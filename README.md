# Brain MRI Classification and Decision Making

Repository for brain MRI classification and clinical decision-making analysis (including Part 1 and Part 2 experiments).

## Dataset

The MRI dataset is omitted from the repository due to file size and can be accessed on Kaggle:
- **PMRAM Bangladeshi Brain Cancer MRI Dataset:** https://www.kaggle.com/datasets/orvile/pmram-bangladeshi-brain-cancer-mri-dataset

## Repository Structure

- `notebooks/`: Jupyter notebook (`brain_mri_classification_decision_making.ipynb`) containing the analysis and modeling workflow.
- `src/`: Workflow and optimization files, including the Orange workflow (`progetto esame orange.ows`), decision data (`aidm_exam_decision.xlsx`), and optimization model (`Lingo_otimaldecision.lg4`).
- `results/`: Output tables, decision summary files (`.xlsx` and `.csv`), confusion matrices, and ROC curve plots.
- `report/`: Final report (`report.pdf`), workflow figure (`OrangeProgetto.png`), and the report slide presentation (to be added).
- `labs/`: Presentation covering the laboratories completed during the course (to be added).
